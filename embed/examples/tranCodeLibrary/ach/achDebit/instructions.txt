Create a transaction code for ACH debit. Use the given ID and set the code to "ACH_DEBIT". The description should be "An ACH debit from an account." The transaction code should have four parameters: account (UUID), amount (DECIMAL), effective (DATE), and currency (STRING). If currency is not provided, it should default to "USD". The transaction code should have two entries: an ACH_DR debit entry and an ACH_CR credit entry. The debit entry should be settled and use the account ID specified in the transaction parameters. The credit entry should be settled and use the given settlement account ID. Return the transaction code ID.
